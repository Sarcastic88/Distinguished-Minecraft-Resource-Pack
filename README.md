# Distinguished-Minecraft-Resource-Pack
This is a Distinguished is a funny Resource Pack that makes mobs distinguished and elegent. It gives most hostile mobs top hats, monocles, and canes.

# Installating Information
Please visit the modrinth page at https://modrinth.com/resourcepack/distinguished if you want to downoald this it makes the process much easier.

If you wish to use this github page you will only need to download the folder labled "Distinguished".

After, you should compress the content of the folder into a zip file.

Rename the file "Distinguished".

Finnally put the zip file into your minecraft/resourcepacks folder.
